★ TOOLS MENTIONED

CHAT — talk to AI

  • Claude — my daily driver. Long memory, Projects, reads big docs

IMAGES — moodboards & references

  • Midjourney — best look for moodboards and refs
  • DALL-E — image gen baked into ChatGPT
  • ComfyUI — local, hackable image gen for the geek crowd

AUDIO / VIDEO — notes from recordings

  • NotebookLM — turns long audio + video into searchable notes
  • Whisper — open-source transcription, runs on your laptop

CODE & AGENTS — AI that does, not just talks

  • Claude Code — AI that writes and runs code with you

SCHEDULE — run things on a timer

  • GitHub Actions — free scheduled jobs in the cloud (for small stuff)
